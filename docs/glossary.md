# Glossary

| Term | Definition |
| --- | --- |
| AAAA | DNS record containing an IPv6 address. |
| API | Application programming interface. |
| CA | Certificate authority trusted to sign certificate chains. |
| DDI | Coordinated DNS, DHCP, and IP address management. |
| DHCP | Protocol for assigning host network configuration, often by lease. |
| DNS | Hierarchical name-resolution system. |
| FQDN | Fully qualified domain name. |
| GTM | Legacy F5 name for BIG-IP DNS/global traffic steering. |
| IPAM | Inventory and allocation management for addresses and prefixes. |
| LTM | F5 local traffic module for virtual-server/load-balancing functions. |
| mTLS | Mutual TLS: client and server both authenticate certificates. |
| Pool | Load-balancer collection of eligible backend members. |
| SAN | Certificate extension containing DNS/IP identities. |
| SNAT | Source network address translation. |
| SNI | TLS ClientHello indication of intended hostname. |
| TLS | Protocol providing authenticated encrypted transport. |
| VIP | Virtual IP / virtual server listener address and port. |
| Wide IP | BIG-IP DNS object mapping an FQDN to global pools/endpoints. |
