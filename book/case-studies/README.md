# Infrastructure case studies

These are fictional incident and migration narratives designed to make the
networking concepts operational. Addresses use documentation ranges and names
are illustrative. Each case separates observed evidence from inferred cause;
no scenario authorizes changing a real F5, DNS, DHCP, or certificate system.

1. [LTM VIP and certificate migration](01-ltm-vip-certificate-migration.md)
2. [GTM multi-site failover](02-gtm-multisite-failover.md)
3. [DDI drift outage](03-ddi-drift-outage.md)
4. [Certificate automation and F5 change safety](04-certificate-automation-change-safety.md)

Read the architecture and timeline first, then pause at the competing
hypotheses before reading the remediation. Use the Q&A to practice explaining
the incident as an SDE1, SDE2, and incident commander.
