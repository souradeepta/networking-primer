# Focused topic references

These nine references are targeted study units for the F5 and DDI portions of
the networking primer. They use fictional names and documentation-oriented
commands. A command that changes state is intentionally shown as a review
pattern, not as an instruction to run against production. Read the protocol
and vendor references linked in each topic alongside the engineering-inference
notes; a recommendation is not the same thing as a product guarantee.

## Suggested order

1. [VIPs and virtual servers](01-vips-and-virtual-servers.md)
2. [Certificates, SNI, and termination](02-certificates-sni-and-termination.md)
3. [LTM monitors, pools, and persistence](03-ltm-monitors-pools-and-persistence.md)
4. [GTM Wide IPs, TTL, and steering](04-gtm-wide-ips-ttl-and-steering.md)
5. [DDI, IPAM ownership, and drift](05-ddi-ipam-ownership-and-drift.md)
6. [F5 automation, SSH, and change safety](06-f5-automation-ssh-and-change-safety.md)
7. [LB device lifecycle and upgrades](07-lb-device-lifecycle-upgrades.md)
8. [Proxy architecture and protocol boundaries](08-proxy-architecture-and-boundaries.md)
9. [Comprehensive F5 SDK](09-f5-sdk-comprehensive.md)

Each topic has objectives, a worked example, a failure section, an operational
checklist, a diagram, and explained questions and answers. Addresses and names
are reserved or local: `198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`,
`app.lab.example`, and `device.example.invalid`.
